## About Me

I am **Aditya Dixit**, a backend and full-stack engineer from India focused on building **AI-enabled web applications, SaaS platforms, APIs, and data-intensive systems**. I work primarily with **Laravel/PHP, Python, REST APIs, relational and NoSQL databases, cloud deployment, and automation**, with an emphasis on shipping reliable, business-ready products.

I enjoy turning unclear business needs into maintainable software: from architecture and database design through API integrations, deployment, monitoring, and iteration. Alongside backend engineering, I build privacy-conscious AI tools using RAG, local LLMs, document processing, and machine-learning workflows.

## Featured Projects

### [MenuHub — Self-Hosted QR Menu SaaS](https://github.com/AdxStackDev/adx_laravel_menuhub)
**Laravel · SaaS · QR Menus · Restaurant Ordering**

A self-hosted platform that lets restaurants and cafés publish digital QR menus and accept browser-based orders without requiring customers to install an app. It demonstrates product thinking, business workflows, and an extensible SaaS foundation.

[Repository](https://github.com/AdxStackDev/adx_laravel_menuhub) · Live demo coming soon

### [AI Document Analyst — Local RAG Knowledge Base](https://github.com/AdxStackDev/laravel_rag_doc_analyst)
**Laravel 13 · Ollama · RAG · Tailwind CSS v4 · Document Processing**

A privacy-first, local knowledge base that enables users to chat with PDFs, Word files, and Excel files without sending documents to third-party AI providers. Built around local LLM inference with Ollama and a practical Laravel application workflow.

[Repository](https://github.com/AdxStackDev/laravel_rag_doc_analyst) · Live demo coming soon

### [Skin Condition Detector — AI Web Application](https://github.com/AdxStackDev/ml_skin1)
**Python · YOLO · Computer Vision · Web Application**

An AI-powered web application for detecting skin conditions with YOLO object-detection models. The project demonstrates applied computer vision and the path from an ML model to a user-facing product.

[Repository](https://github.com/AdxStackDev/ml_skin1)

### [Event Management System — Laravel + MongoDB](https://github.com/AdxStackDev/larav_eventos)
**Laravel 12 · MongoDB · REST API · Tickets · Subscriptions**

A comprehensive event-management backend with RESTful APIs for events, tickets, subscriptions, categories, locations, and tags. It demonstrates API design, domain modeling, and work with a NoSQL database.

[Repository](https://github.com/AdxStackDev/larav_eventos)

### [NSE F&O Participant Dashboard](https://github.com/AdxStackDev/php_nse_oi_data)
**PHP · Financial Data · Analytics Dashboard · Market Sentiment**

A dashboard for analyzing NSE Futures and Options participant-wise data, helping users track positions across Clients, FIIs, DIIs, and PROs and identify potential market-sentiment shifts.

[Repository](https://github.com/AdxStackDev/php_nse_oi_data)

### [Portfolio — Astro, React, and Tailwind](https://github.com/AdxStackDev/my-portfolio)
**Astro · React · TypeScript · Tailwind CSS**

A modern, responsive developer portfolio with dark/light mode, polished animations, and fast performance.

[Repository](https://github.com/AdxStackDev/my-portfolio) · [Visit portfolio](https://adxdev.vercel.app/)
